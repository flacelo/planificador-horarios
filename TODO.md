# Ideas futuras de PLANIFY

Estas son posibilidades para explorar después de estabilizar la edición y completar las pruebas móviles descritas en el [roadmap](ROADMAP.md).

- Plantillas compartibles sin incluir datos personales de quien las creó.
- Más opciones de informes y estadísticas comprensibles.
- Sincronización de calendario y entre dispositivos, solo si se define una arquitectura de privacidad y seguridad adecuada.
- Mejoras de accesibilidad y uso sin conexión verificadas en navegadores reales.

La aplicación actual genera sugerencias mediante reglas locales. No tiene integración de IA generativa ni requiere que las personas paguen una API.
